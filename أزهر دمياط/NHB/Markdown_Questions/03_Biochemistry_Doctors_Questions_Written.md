### Question 1

Explain: Glutathione Peroxidase as an Antioxidant:

**Type**: QROC
**Correct Answer**: -
**Explanation**: Glutathione peroxidase is an antioxidant enzyme that detoxifies hydrogen peroxide and lipid peroxides.
It uses reduced glutathione (GSH), converting it into oxidized glutathione (GSSG).
GSSG is then recycled back to GSH by glutathione reductase using NADPH.
