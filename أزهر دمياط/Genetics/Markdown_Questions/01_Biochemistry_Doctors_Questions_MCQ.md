# Biochemistry Doctor's Questions (MCQ)

### Q1: A nucleotide consists of:
- **A)** A nitrogenous base like choline
- **B)** Purine or pyrimidine base + sugar + phosphorous
- **C)** Purine or pyrimidine base + sugar
- **D)** Purine or pyrimidine base + phosphorous

**Correct Answer:** B

---

### Q2: A purine nucleotide is:
- **A)** AMP
- **B)** UMP
- **C)** CMP
- **D)** TMP

**Correct Answer:** A

---

### Q3: A pyrimidine nucleotide is:
- **A)** GMP
- **B)** AMP
- **C)** CMP
- **D)** IMP

**Correct Answer:** C

---

### Q4: The nucleic acid base found in mRNA but not in DNA is:
- **A)** Adenine
- **B)** Cytosine
- **C)** Guanine
- **D)** Uracil

**Correct Answer:** D

---

### Q5: The nitrogenous base present in the RNA molecule is:
- **A)** Thymine
- **B)** Uracil
- **C)** Xanthine
- **D)** Hypoxanthine

**Correct Answer:** B

---

### Q6: RNA does not contain:
- **A)** Uracil
- **B)** Adenine
- **C)** Thymine
- **D)** Ribose

**Correct Answer:** C

---

### Q7: One of the following nucleotides acts as a second messenger:
- **A)** SAM
- **B)** GTP
- **C)** cAMP
- **D)** ATP

**Correct Answer:** C

---

### Q8: Coenzyme A is one of the few nucleotides which acts as:
- **A)** Acid carrier
- **B)** Second messenger
- **C)** Methyl donor
- **D)** Hydrogen carrier

**Correct Answer:** A

---

### Q9: In RNA molecule 'Caps':
- **A)** Allow tRNA to be processed
- **B)** Are unique to eukaryotic mRNA
- **C)** Occur at the 3' end of tRNA
- **D)** Allow correct translation of prokaryotic mRNA

**Correct Answer:** B

---

### Q10: In contrast to eukaryotic mRNA, prokaryotic mRNA:
- **A)** Can be polycistronic
- **B)** Is synthesized with introns
- **C)** Can only be monocistronic
- **D)** Has a poly A tail

**Correct Answer:** A

---

### Q11: DNA rich in G-C pairs have:
- **A)** 1 hydrogen bond
- **B)** 2 hydrogen bonds
- **C)** 3 hydrogen bonds
- **D)** 4 hydrogen bonds

**Correct Answer:** C

---

### Q12: In tRNA molecule, the D arm is named for the presence of the base:
- **A)** Uridine
- **B)** Pseudouridine
- **C)** Dihydrouridine
- **D)** Thymidine

**Correct Answer:** C
