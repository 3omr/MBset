# Subcategories & Lecture Processing Guide

This guide describes how to process raw lecture PDFs into standard MBset subcategories and official platform-ready lecture files.

## Workflow

### 1. Surveying Lecture Files
Scan the module's raw lectures directory (e.g., `NHB/Lectuers/` or `biomedical/Lectures/`). Identify:
* Topics split into multiple parts (e.g., `Joints Part 1.pdf`, `Joints Part 2.pdf`).
* Independent single-topic lectures.

### 2. Multi-Part Merging Decision Matrix
Consult the user before finalizing subcategory boundaries:
* **Recommended to Merge**:
  - Part 1 & Part 2 covering consecutive slides of a single syllabus item (e.g., `Proteins 1 & 2`, `Sympathetic NS I, II, III`, `Locomotor Joints 1 & 2`, `Free Radicals 1 & 2`).
  - PyMuPDF (`fitz`) merge command:
    ```python
    import fitz
    doc = fitz.open(part1_path)
    doc2 = fitz.open(part2_path)
    doc.insert_pdf(doc2)
    doc.save(merged_output_path)
    ```
* **Keep Separate if Requested**:
  - Distinct sub-topics (e.g., `Systems of the Body`, `Epithelium`, `Connective Tissue`, `Cell Transport`).

### 3. Two-Phase Workflow & Subcategories Schema
* **Phase 1 (Initial Lectures File)**:
  - Generate `subcategories_<Module>.xlsx`.
  - Columns: `categoryId`, `categoryName`, `subcategoryId`, `name`, `tag`, `type`, `pdf`, `studyRecommendations`, `pdfVersion`, `pdfDate`, `pdfNote`, `questionsCount`, `orderIndex`.
  - **`categoryId` & `subcategoryId` MUST be left completely empty (`None`)**.
  - Present the detailed breakdown of lectures to the user, and **PAUSE** for the user to upload it to the platform.

* **Phase 2 (After Platform Upload & Export)**:
  - The platform exports the official file: `subcategories_<Module>_<Date>.xlsx` containing the autogenerated `subcategoryId`s.
  - This official export becomes the immutable single source of truth. Temporary subcategory files must be deleted.
  - Proceed to rename lecture PDFs in `Lectures/` and compile `<Module>_Questions.xlsx`.

### 5. Final Lectures Directory Structure
Rename every lecture PDF in `<Module>/Lectures/` to `<subcategoryId>.pdf`:
```
NHB/
└── Lectures/
    ├── DamiettaFa_NORMAL_HUMAN_BODY_ACTION_POTENTIAL.pdf
    ├── DamiettaFa_NORMAL_HUMAN_BODY_ACTIVE_TRANSPORT_ACROSS_CELL.pdf
    └── ...
```
Total PDF count in `Lectures/` must match the subcategories count exactly.
